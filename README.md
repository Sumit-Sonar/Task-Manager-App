# Task Manager App

This Task Manager app was developed to enhance my understanding of Flutter's **Provider State Management**. The project focuses on efficiently managing and structuring state within a scalable Flutter application, offering a practical demonstration of state management and app architecture best practices.

## Features

- **Task Management**: Add, update, and delete tasks efficiently.
- **Task Categorization**: Organize tasks based on priority, categories, and due dates.
- **State Management**: Implements Flutter's `Provider` for effective state handling.
- **Real-time Updates**: Seamless task state updates across the app.
- **Responsive UI**: Clean and responsive interface adaptable to different screen sizes.

## Tech Stack

- **Flutter**: The UI framework used to build the app.
- **Provider**: For efficient and scalable state management.
- **SharedPreferences**: Used for storing task-related data persistently on the device.
  
## Getting Started

### Prerequisites

- Flutter SDK: [Install Flutter](https://flutter.dev/docs/get-started/install)
- A code editor such as [VSCode](https://code.visualstudio.com/) or [Android Studio](https://developer.android.com/studio)

### Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/task_manager.git
    ```

2. Navigate to the project directory:
    ```bash
    cd task_manager
    ```

3. Install dependencies:
    ```bash
    flutter pub get
    ```

4. Run the app:
    ```bash
    flutter run
    ```

## How to Use

1. **Add a Task**: Use the task form to add a new task with a title, description, and optional due date.
2. **Update/Delete Tasks**: Swipe left to delete tasks or click on a task to update its details.
3. **State Management**: All changes are reflected instantly using the `Provider` state management solution.
